# Materia-Inteligencia-Artificial-6-periodo
50 Exercícios de Python — Amanda Barreto
Turma A, Período 6

Repositório desenvolvido por **Amanda Barreto** como atividade da disciplina de **Inteligência Artificial — 6º período, Turma A**.

O projeto reúne **50 exercícios de Python** desenvolvidos com o objetivo de praticar e fortalecer os fundamentos de programação necessários para o estudo de Inteligência Artificial.

Os exercícios começam com conceitos básicos de lógica de programação e evoluem gradualmente para estruturas de dados, algoritmos de busca e ordenação, manipulação de strings, funções, recursão, criptografia, validação de dados e pequenos projetos.

# Objetivo

O principal objetivo deste repositório é consolidar os fundamentos da linguagem Python por meio da resolução de problemas práticos.

# Como cada exercício está organizado

Todos seguem o mesmo formato, pra facilitar a leitura:

Enunciado — o que o exercício pede
Código — a solução em Python
Explicação — o raciocínio por trás da solução

# Como executar

Os exercícios estão disponíveis em formato **Jupyter Notebook (`.ipynb`)**.

Você pode executá-los utilizando:

- Google Colab
- Jupyter Notebook
- JupyterLab
- VS Code com suporte a notebooks

### Google Colab

1. Acesse o Google Colab.
2. Abra o arquivo `.ipynb`.
3. Execute as células em ordem.
4. Nos exercícios que utilizam `input()`, digite os valores solicitados.
