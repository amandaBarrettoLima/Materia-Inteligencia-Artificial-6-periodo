# Materia-Inteligencia-Artificial-6-periodo
50 Exercícios de Python — Amanda Barreto
Turma A, Período 6

Esse repositório reúne os 50 exercícios de lógica de programação que resolvi como parte introdutória da matéria de Inteligência Artificial. Antes de chegar em modelos, algoritmos de IA e afins, a ideia era firmar bem a base em Python, e foi exatamente pra isso que serviram esses exercícios: do "Hello, World!" até coisas um pouco mais encorpadas como jogo da velha, cifra de César e validador de CPF.

O que tem no notebook

O arquivo Exercícios_Python__AmandaBarreto__Turma_A__Período_6_.ipynb contém os 50 exercícios em ordem.

Como rodar
Abra o notebook no Google Colab ou no Jupyter Notebook de sua preferência.
Rode as células em ordem. Vários exercícios usam input(), então o programa vai parar esperando você digitar alguma coisa.
Para o exercício 28, é preciso ter o matplotlib instalado:
bash
pip install matplotlib
Como cada exercício está organizado

Enunciado — o que o exercício pede
Código — a solução em Python
Explicação — o raciocínio por trás da solução
