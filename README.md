# 130 Exercícios de Python — Amanda Barreto

**Turma A · 6º Período**

Repositório desenvolvido por Amanda Barreto como atividade da disciplina de **Inteligência Artificial** — 6º período, Turma A.

O projeto reúne **130 exercícios de Python**, divididos em duas partes:

- **Parte 1 — Fundamentos de Python (50 exercícios):** desenvolvidos com o objetivo de praticar e fortalecer os fundamentos de programação necessários para o estudo de Inteligência Artificial. Começam com conceitos básicos de lógica de programação e evoluem gradualmente para estruturas de dados, algoritmos de busca e ordenação, manipulação de strings, funções, recursão, criptografia, validação de dados e pequenos projetos.
- **Parte 2 — Ciência de Dados com NumPy, SciPy, Pandas e Matplotlib (80 exercícios):** focados nas bibliotecas mais usadas em Inteligência Artificial e análise de dados, cobrindo manipulação de arrays, álgebra linear, otimização, estatística, manipulação de tabelas e visualização de dados.

---

## Objetivo

O principal objetivo deste repositório é consolidar os fundamentos da linguagem Python por meio da resolução de problemas práticos.

## Como cada exercício está organizado

Todos seguem o mesmo formato, para facilitar a leitura:

- **Enunciado** — o que o exercício pede
- **Código** — a solução em Python
- **Explicação** — o raciocínio por trás da solução

## Tecnologias utilizadas

**Linguagem**
- Python 3

**Bibliotecas — Parte 1 (Fundamentos)**
- `math` — operações matemáticas
- `random` — geração de valores aleatórios
- `matplotlib` — criação de gráficos

> A biblioteca Matplotlib é utilizada especificamente no exercício 28, na Parte 1.

**Bibliotecas — Parte 2 (Ciência de Dados)**
- `numpy` — manipulação de arrays e álgebra linear (exercícios 51–70)
- `scipy` — computação científica: otimização, integração, álgebra linear avançada, interpolação e transformadas de Fourier (exercícios 71–90)
- `pandas` — manipulação e análise de dados tabulares (exercícios 91–110)
- `matplotlib` — visualização de dados (exercícios 111–130)
- `openpyxl` — motor necessário para o Pandas ler e escrever arquivos `.xlsx` (usado no exercício 92)

## Como executar

Os exercícios estão disponíveis em formato Jupyter Notebook (`.ipynb`).

Você pode executá-los utilizando:

- Google Colab
- Jupyter Notebook
- JupyterLab
- VS Code com suporte a notebooks

### Google Colab

1. Acesse o [Google Colab](https://colab.research.google.com).
2. Abra o arquivo `.ipynb`.
3. Execute as células em ordem.
4. Nos exercícios que utilizam `input()`, digite os valores solicitados.

### Instalação das bibliotecas

Caso esteja executando o projeto localmente, instale as dependências necessárias:

```bash
# Necessário apenas para a Parte 1 (exercício 28)
pip install matplotlib

# Necessário para a Parte 2 (exercícios 51–130)
pip install numpy scipy pandas matplotlib openpyxl
```

No Google Colab, `numpy`, `scipy`, `pandas`, `matplotlib` e `openpyxl` já vêm pré-instalados — não é necessário rodar nenhum comando extra na maioria dos casos.
