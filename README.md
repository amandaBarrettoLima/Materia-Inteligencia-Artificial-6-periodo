## Modelos de classificação: SVM e Árvores de Decisão

Além dos exercícios de Python, o repositório reúne notebooks de **aprendizado de máquina supervisionado** aplicados a problemas de classificação:

- **`notebook-svm.ipynb`** — modelo SVM (Support Vector Machine).
- **`modelo com svm e arvores [Amanda Barreto 6A].ipynb`** — modelos com SVM e Árvores de Decisão.
- **`classifica-o-do-breast-cancer-wisconsin.ipynb`** — classificação do dataset *Breast Cancer Wisconsin*.

Nesses notebooks são praticadas as etapas típicas de um projeto de classificação: leitura e limpeza dos dados, divisão em treino e teste, treinamento dos modelos, ajuste de hiperparâmetros e avaliação por métricas como acurácia e matriz de confusão.

## Tecnologias utilizadas

**Linguagem**

- Python 3

**Bibliotecas — Parte 1 (Fundamentos)**

- `math` — operações matemáticas
- `random` — geração de valores aleatórios
- `matplotlib` — criação de gráficos (exercício 28)

**Bibliotecas — Parte 2 (Ciência de Dados)**

- `numpy` — manipulação de arrays e álgebra linear (exercícios 51–70)
- `scipy` — computação científica: otimização, integração, álgebra linear avançada, interpolação e transformadas de Fourier (exercícios 71–90)
- `pandas` — manipulação e análise de dados tabulares (exercícios 91–110)
- `matplotlib` — visualização de dados (exercícios 111–130)
- `openpyxl` — motor para o Pandas ler e escrever arquivos `.xlsx` (exercício 92)

**Bibliotecas — Modelos de classificação**

- `scikit-learn` — SVM, Árvores de Decisão, divisão treino/teste e métricas de avaliação
- `pandas`, `numpy` e `matplotlib` — preparação dos dados e gráficos

## Como executar

Os trabalhos estão em formato Jupyter Notebook (`.ipynb`). Você pode executá-los com:

- Google Colab
- Jupyter Notebook
- JupyterLab
- VS Code com suporte a notebooks

### Google Colab

1. Acesse o [Google Colab](https://colab.research.google.com).
2. Abra o arquivo `.ipynb`.
3. Execute as células em ordem.
4. Nos exercícios que utilizam `input()`, digite os valores solicitados.

### Instalação das bibliotecas (execução local)

```bash
# Parte 1 (exercício 28)
pip install matplotlib

# Parte 2 (exercícios 51–130)
pip install numpy scipy pandas matplotlib openpyxl

# Modelos de classificação
pip install scikit-learn pandas numpy matplotlib
```

No Google Colab, `numpy`, `scipy`, `pandas`, `matplotlib`, `scikit-learn` e `openpyxl` já vêm pré-instalados, então normalmente não é necessário rodar nenhum comando extra.
